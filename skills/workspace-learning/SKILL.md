# Workspace learning

Learn from evidence, not personality guesses. Keep raw observations separate from rules that will affect future runs.

## 1. Collect

Read only the workspace sources the user has authorized: recent card threads, completed work, explicit corrections, and action outcomes. Capture compact observations with:

- the behavior or correction;
- the source item/date;
- attribution to the user or agent;
- whether it confirms, contradicts, or merely suggests a pattern.

Do not promote an inference as the user's position.

## 2. Curate

Group repeated observations and decide for each candidate:

- **ADD** — repeated evidence supports a new rule;
- **CONFIRM** — an existing rule still predicts behavior;
- **CONTRADICT** — newer evidence challenges a rule;
- **NOOP** — interesting but not durable or actionable.

Propose only the handful of rules that would materially change a future agent's behavior. Show the evidence and target file. The user approves promotion.

## 3. Write the smallest rule

Write the essence in plain language for a future agent with no session history. Include source attribution where authorship matters. Do not invent rationale, ceremonies, or confirmations the user did not give.

## 4. Meta-review

Periodically sample promoted rules against later work:

- Did the rule prevent a repeated mistake?
- Did it trigger when relevant?
- Did it create unnecessary questions or rigidity?
- Is it stale, contradicted, or duplicated elsewhere?

Revise or retire rules with the same evidence discipline used to create them. If there is not enough real use, say so and stop.
